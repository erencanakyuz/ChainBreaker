🪐 GAME VIEWPORT
Test paneli sol üstte görünecek

📋 Nasıl Kullanılır:

  1. Yukarıdaki "TEST ARAYÜZÜNÜ BAŞLAT" butonuna tıklayın
  2. Sol üstte test paneli açılacak
  3. Test panelindeki butonlarla Pluto'yu test edin
  4. Klavye kısayolları: Ctrl+1 (Panel Aç/Kapat), Ctrl+2 (Debug), Ctrl+R (Reset)
  5. Panel başlığındaki "━" butonuyla paneli küçültebilirsiniz
